# Google Play Data safety worksheet

Use this as the implementation-backed starting point for Play Console. Reconfirm every answer against the production Supabase deployment and any SDK added after this document was written.

## On-device only

- Android app names/package names and foreground durations are processed ephemerally on the device.
- They are not stored in the FlowSight database, exported, uploaded, or shared.
- Under Google Play's Data safety definitions, data processed only on-device is not declared as collected. Confirm this interpretation when submitting because policy wording can change.

## Data that may be collected

| Data type | Condition | Purpose | Shared | Required |
|---|---|---|---|---|
| Email address | User creates/signs into an optional account | Account management | No | No |
| User ID | User signs in | Account management and authenticated sync | No | No |
| Focus-session timestamps, duration, category, pause count, optional task/ticket fields | User enables cloud sync | App functionality and cross-device sync | No | No |
| Installation/device identifier generated by FlowSight | User signs in or syncs | Device registration, integrity, and sync | No | No |

All transmitted data is encrypted in transit. Users can request deletion in-app. No advertising, sale, or third-party data brokerage is present.

## Permission declaration

`android.permission.PACKAGE_USAGE_STATS` is used for the app's core focus-session insight feature. The in-app disclosure appears before the system settings screen and states exactly which data is read, for what interval, how it is used, and that per-app rows are not uploaded.

FlowSight does not request `QUERY_ALL_PACKAGES`, Accessibility Service, screen capture, notification-listener access, exact-alarm access, contacts, location, microphone, camera, or storage permissions. It requests `POST_NOTIFICATIONS` only when the user opts into local focus reminders on Android 13 or newer.
