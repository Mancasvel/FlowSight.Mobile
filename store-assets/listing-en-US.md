# Google Play listing — en-US

## App name

FlowSight

## Short description

Private focus timer with on-device Android app activity insights.

## Full description

Build focused work sessions and understand where the time went.

FlowSight gives you a reliable Start, Pause, Resume, and Stop timer, then can show foreground app time for that session using Android Usage Access. Detailed app activity stays on your device and is never uploaded.

Features:

- Focus timer that survives backgrounding and relaunches
- Per-app session timeline with optional Android Usage Access
- Local trends, session history, and interruption patterns
- Light and dark themes
- Optional account and opt-in session-total sync
- Local data export, local deletion, and account deletion controls
- No ads and no in-app purchases

Usage Access is optional. Without it, every timer and session-history feature still works; only the per-app breakdown is unavailable. FlowSight never reads screen contents, typed text, messages, files, or browsing history.
